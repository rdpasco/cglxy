Introduction

Welcome to Lecture 1 of the Post-GWAS Analysis Training course. In this session, we will explore the CropGalaxy environment, familiarize ourselves with its interface, and learn how to efficiently navigate the tools for post-GWAS analysis.

Learning Objectives

  • Understand the layout and structure of the CropGalaxy interface.
  • Identify the three main working panels.
  • Learn how to access core analysis tools.
  • Understand how datasets and histories are managed.

Lecture Content

We will begin by opening CropGalaxy and reviewing the main interface components, including the tool panel, workspace, and history panel. A guided walkthrough will demonstrate how to search for tools, execute analyses, and manage results.

By the end of this lecture, you should feel confident navigating the platform and identifying the key features required for downstream post-GWAS analysis workflows.

Next Steps

After completing this lecture, proceed to Exercise 1 to practice navigating the CropGalaxy interface using real datasets.
