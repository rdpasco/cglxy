Lecture 1: Exploring the CropGalaxy Environment

Familiarize yourself with the CropGalaxy interface and tools

Learning Objectives

  • Understand the layout and structure of the CropGalaxy interface
  • Identify the three main working panels
  • Learn how to access core analysis tools
  • Understand how datasets and histories are managed

Lecture Content

We will explore the main interface components of CropGalaxy, including the tool panel, workspace, and history panel. A guided walkthrough demonstrates how to search for tools, execute analyses, and manage results.

By the end of this lecture, you should feel confident navigating the platform and identifying key features required for downstream post-GWAS analysis workflows.
