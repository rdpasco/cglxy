Lecture 1

Exploring the CropGalaxy Environment

Introduction

Welcome to Lecture 1 of the Post-GWAS Analysis Training course. In this lecture, we will explore the CropGalaxy environment, familiarize ourselves with its interface, and learn how to navigate the tools for post-GWAS analysis.

Objectives

  • Understand the layout of CropGalaxy.
  • Learn how to access and use core tools for analysis.
  • Explore sample datasets and workflow management.

Content

We will start by opening CropGalaxy, exploring the menus and tools available, and then perform a guided walkthrough using a sample dataset. By the end of this lecture, you should feel confident navigating the platform and identifying the main features relevant to post-GWAS analysis.

Next Steps

After completing this lecture, proceed to Exercise 1 to practice navigating the CropGalaxy interface using real datasets.
