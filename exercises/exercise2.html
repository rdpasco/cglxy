Exercise 2

Identifying Candidate Genes from a Genomic Region of Interest

Objective

Learn how to identify candidate genes from a genomic region of interest using CropGalaxy and its integrated tools.

Instructions

  1. Open CropGalaxy. You will see three main panels on the landing page:
    • Left panel: All available tools.
    • Right panel: Current analysis history, showing datasets generated from each tool run.
    • Middle panel: Analysis workspace displaying tool parameters and selected dataset contents.
  2. Select the RiceGalaxy: SNP Data Tools suite from the tool panel. This contains the specific tool needed for candidate gene analysis.
    Tip: You can also use the search bar to locate the tool quickly.
