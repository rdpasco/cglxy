Objective

Learn how to identify candidate genes from a genomic region of interest using CropGalaxy and its integrated tools.

Preparation

  1. Open CropGalaxy. You will see three main panels:
    • Left panel: Available tools
    • Middle panel: Analysis workspace
    • Right panel: Analysis history
  2. Select the RiceGalaxy: SNP Data Tools suite.
    Tip: Use the search bar to locate tools faster.

Liftover_via_SNP

This tool maps genomic regions from a source genome to a target genome using SNP-guided alignment.

  1. Select RiceGalaxy: SNP Data Tools.
  2. Select the Liftover_via_SNP tool.
  3. Configure Lift-Over parameters:
    1. Source genome: Nipponbare
    2. Coordinates: Chr02:22001414–22831782
    3. Target genome: N22
    4. Select N22 as target genome
    5. Leave other settings as default

  4. Rename history to: PostGWAS hands-on
  5. Click Run Tool
  6. Viewing output datasets: Click the View Data icon

Blat Alignment Filter

Examine the alignment result. Notice that it shows multiple hits on the probable location of the lift-over coordinates. So we need to filter this using the tool: Blat Alignment Filter

The blat-alignment-filter parses alignment output of blat and find-seq (supports only blat psl format output), allowing for selection of alignments that pass specified criteria (# max mismatches, how much of query length is aligned). It uses "awk" Linux utility in the background to filter the alignment results.


  1. Select the Blat Alignment Filter tool under SNP Data Tools.

  2. Set parameters:
    1. Input dataset: Liftover_via_SNP output
    2. Percent of length of query sequence that matches target sequence (usually 50 - 100%): 90%
    3. Leave other settings as default

  3. Click Run Tool

  4. Click on the View Data button to see the result file. You will see that the resulting file now only has two entries.

  5. Lifted-over coordinates on N22: You now have the new coordinates in N22 genome.
    1. Copy the chromosome Chr02.
    2. Copy the value of the first entry in "T start" (Column 16). This will become your lower bound coordinate: 22947842
    3. Copy the value of the second entry in "T end" (Column 17). This will become your upper bound coordinate: 23769036

    The N22 genome coordinate of the lifted-over QTL is: Chr02:22947842-23769036

Get-genes-by-region(s) IDs v2

Now, we want to look for candidate genes that lie in this region.

  1. Go to RiceGalaxy: SNP Data tools suite again and select Get Genes from Region IDs v2.
  2. Set parameters:
    1. Set the Reference genomes to get genes to : Oryza sativa N22 (aus) new annotation
    2. Set Gene or mRNA to: mRNA
    3. Set Type in a region directly (chr:start-end), OR use regions list from history? to: Directly type-in region
    4. To extract the genes in the QTL from N22 mRNA; use the lower & upper bound of the lift-over results. We will use here the one we got from the previous step: Chr02:22947842-23769036.
    5. Once the parameters are set, click Run Tool
  3. Click Run Tool
  4. Click on the View Data to see the list of genes.

    You will see that there are 141 genes (mRNA) in the lift-over region from N22 reference genome.

Get-subseq

Retrieves nucleotide sequences of candidate genes for downstream functional analysis.

  1. Select Get-subseq tool.
  2. Set parameters:
    1. Set the output of the previous tool as input.
    2. Set gene ID column to: Column: 5
    3. Set “Will you select a multiFASTA sequence from history or use a built-in rice genome database?” to: Use a built -in gene database
    4. Set Select reference database to: N22
    5. Once the parameters are set, click Run Tool
  3. Click Run Tool
  4. Click on the View Data to display output.

    5. You will see that you have now retrieved the nucleotide sequences of all the candidate genes in the lifted-over region. These sequences can be used for downstream functional analysis and gene prioritization.
