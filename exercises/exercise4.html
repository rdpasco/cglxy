Phylogenetic Tree Construction

Using Galaxy Platform

Objective

Learn how to construct and interpret a phylogenetic tree using protein sequences.

Step 1: Upload Accession Numbers

  1. Open Galaxy
  2. Click Upload Data
  3. Paste the following:
YP_009724390.1
YP_009825051.1
YP_009047204.1
YP_009555241.1

Click Start → Close

Step 2: Download Protein Sequences

  1. Go to Get Data → NCBI Accession Download
  2. Set:
    • Input: Uploaded list
    • Molecule type: Protein
  3. Click Run Tool

Step 3: Multiple Sequence Alignment (MAFFT)

  1. Go to Multiple Alignments → MAFFT
  2. Input: Downloaded sequences
  3. Click Run Tool

Step 4: Build Phylogenetic Tree

  1. Go to Phylogenetics → FastTree
  2. Input: MAFFT output
  3. Click Run Tool

Step 5: Visualize Tree

  1. Go to Visualization → Newick Display
  2. Select FastTree output
  3. Click Run Tool

Step 6: Interpret Results

Use LLM Hub and enter:

Describe the overall structure of this phylogenetic tree.
Identify major clusters and explain what they indicate about evolutionary relationships.

Expected Output

  • Aligned sequences (MSA)
  • Phylogenetic tree file
  • Tree visualization
  • Interpretation of evolutionary relationships
