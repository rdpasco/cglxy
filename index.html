A comprehensive hands-on training for post-GWAS candidate gene analysis using the CropGalaxy platform.

Start Learning

Training Overview

This training provides structured guidance on how to analyze genome-wide association study (GWAS) results and identify candidate genes using CropGalaxy.

Participants will explore genomic datasets, navigate integrated tools, interpret gene annotations, and perform candidate gene prioritization using real rice genomic data.

The program is self-paced and designed to bridge the gap between GWAS results and biological interpretation.

Learning Objectives

  • Understand the CropGalaxy interface and integrated genomic tools
  • Navigate genome browsers and genomic datasets
  • Identify candidate genes from GWAS loci
  • Interpret gene annotations and functional information
  • Apply structured post-GWAS analysis workflows

Training Modules

Module 1: Introduction to CropGalaxy

Learn the interface, navigation, and core features of the platform.

Module 2: Identifying Candidate Genes

Discover how to locate genes associated with GWAS loci.

Module 3: Investigating Gene Functions

Interpret gene annotation and functional evidence using Nipponbare datasets.

Hands-on Exercises

Apply your knowledge using guided practical activities.

Target Audience

  • Graduate students in genomics, bioinformatics, and plant science
  • Researchers conducting GWAS analysis
  • Plant breeders and geneticists
  • Bioinformaticians analyzing crop genomic data

Prerequisites

  • Basic knowledge of genetics or genomics
  • Familiarity with GWAS concepts (recommended)
  • Basic computer skills
